# GroupsApp — Sistema de Mensajería Distribuida

Aplicación de mensajería instantánea similar a WhatsApp/Telegram, con arquitectura cliente-servidor moderna y escalable.

## Estructura del proyecto

```
.
├── frontend/   # Aplicación React
├── docs/       # Documentación
├── README.md
└── .gitignore
```

## Tecnologías

- **Frontend:** React
- **Backend:** Django (REST Framework)

## Inicio rápido

```bash
# Frontend
cd frontend
npm install
npm start

# Backend
cd backend
pip install -r requirements.txt
python manage.py runserver
```
